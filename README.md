# Продуктовый навигатор

**ИИ-агент в папке проекта: от размытого запроса до проверяемой стратегии и её пересмотра.**
Открой репозиторий в Cursor/Codex или запусти CLI через OpenRouter. Постоянные инструкции,
методика, материалы, свидетельства и состояние хранятся отдельно. Интерфейс сайта не нужен.

Предварительное демо — **«Круг доверия»**, семейный цифровой сервис. Официальный бриф
МегаФона ещё не предоставлен. Публичные сведения, авторские гипотезы и учебные данные
явно разделены. Это не официальный продукт и не исследование закрытых данных оператора.

## Быстрый старт без ключа

Нужен Python 3.12 или новее. Базовый запуск не требует установки библиотек.

```bash
python -m strategy_agent doctor
python scripts/demo.py --project workspace/demo --phase pause
python scripts/demo.py --project workspace/demo --phase finish
python -m strategy_agent status --project workspace/demo
python scripts/demo.py --project workspace/demo --phase revise
python -m unittest discover -s tests -v
```

Первая команда демо оставляет сохранённую контрольную точку, вторая продолжает её в новом
процессе. Результаты находятся в `workspace/demo/artifacts/`. **Это воспроизведение заранее
подготовленного сценария с настоящими локальными инструментами, без вызова LLM.** Оно
проверяет расчёты, источники, состояние и запрос решения; не доказывает качество модели.
Новая папка обязательна: скрипт не стирает существующий проект.

Готовое исследование: [демонстрационный проект](examples/family-safety/brief.md).
Описание для подачи: [PDF](submission/description.pdf), [HTML](submission/description.html).
Проверки: [validation.json](submission/validation.json).

## Работа в Cursor/Codex

Открой корень репозитория. Начни с запроса:

> Прочитай AGENTS.md. Создай исследование в workspace/my-product. Проблема: падает
> активация семейного сервиса. Материалы добавлю в materials. Уточни только то, что
> меняет следующий шаг, сохрани источники и сравни варианты перед рекомендацией.

`AGENTS.md` и `.cursor/rules/` направляют работу; `.agents/skills/` содержит повторяемые
процедуры исследования и пересмотра. Модель среды может использовать локальные инструменты
без ключа OpenRouter. Стоимость подписки или API среды учитывается отдельно.

Для локального MCP создай конфигурацию клиента по [docs/MCP.md](docs/MCP.md).
Инструменты не открывают сервер в интернете и не запускают внешние действия.

## Живой агент через OpenRouter

Скопируй `.env.example` в `.env`, если файл ещё не создан, и заполни `OPENROUTER_API_KEY`.
Ключ не нужно вставлять в код или чат. `.env` исключён из Git. Модели настраиваются
в `.env`; доступность и поддержку инструментов проверяет `doctor --online`.

```bash
python -m strategy_agent doctor --online
python -m strategy_agent init --project workspace/live --brief examples/family-safety/brief.md --budget 2
python scripts/prepare_project.py --project workspace/live --example examples/family-safety
python -m strategy_agent run --project workspace/live --max-steps 30
```

Модель сама выбирает инструменты, читает результаты, привлекает критика или модельного
респондента при необходимости и сохраняет стратегию. Данные, прочитанные моделью, могут
передаваться через OpenRouter: используй разрешённые материалы. Платные сервисы — только
модели OpenRouter (или модель своей IDE); поиск внутри проекта и расчёты локальные.
Тарифы не зашиты в код: перед запросом проверяется каталог, после него сохраняется `usage.cost`.
Бюджет — ограничитель запуска новых запросов, а не гарантия возврата уже потраченных средств.

## Управление и продолжение

```bash
python -m strategy_agent pause --project workspace/live
python -m strategy_agent status --project workspace/live
python -m strategy_agent answer --project workspace/live --text "Не рассматриваем расширение штата поддержки"
python -m strategy_agent resume --project workspace/live --max-steps 20
python -m strategy_agent review --project workspace/live
```

Пауза срабатывает перед следующим действием; уже отправленный запрос может завершиться.
При новом чате прочитай `state/state.json`, `state/events.jsonl` и реестры в `artifacts/`.
При переносе на другую машину копируй папку проекта целиком; ключ остаётся в окружении.
`review` проверяет сроки и актуальность оснований утверждённого решения. При изменении
возвращает его на пересмотр, сохраняя историю. Для офлайн-примера `--phase revise` загружает
новое учебное условие, пересчитывает экономику и обновляет обе стратегии.

Когда статус `awaiting_approval`, прочитай `artifacts/strategy.md`, затем зафиксируй
выбранный **существующий ID варианта** и обязательство проверки. Пример формы команды:

```bash
python -m strategy_agent approve --project workspace/live --option pilot --note "Проверяем согласие до масштабирования" --owner "Руководитель продукта" --metric "Доля завершённых подключений" --threshold "Пересмотр при росте обращений в поддержку" --due 2026-12-01
```

Дата, владелец и порог в примере заменяются условиями своего проекта. Подтверждение
сохраняет локальное решение; оно не запускает кампанию. Для изменений используй `answer`.
Для разбора прерванного вызова или неизвестной стоимости:
`python -m strategy_agent resolve-tool --help` и `reconcile-cost --help`.
Платный запрос с неопределённым результатом не повторяется автоматически.

## Что реализовано

| Возможность | Как проверить |
|---|---|
| Агентный цикл с выбором инструментов | OpenRouter live-режим; тесты с фиксированными ответами проверяют механику |
| Источники, факты, гипотезы, прогнозы | Реестры с локаторами, хешами и происхождением |
| Документы, таблицы, сайты | TXT/MD/CSV/JSON/HTML/DOCX/XLSX; разрешённые HTTPS-домены |
| PDF, аудио/видео | PDF с текстовым слоем через pypdf; SRT/VTT с таймкодами; исходные медиа не распознаются CLI |
| Интервью и UX | Аннотации с точным локатором; отдельный синтетический респондент и критик |
| Количественный анализ | Отношение сумм, Wilson 95%, планирование A/B, экономика сценариев |
| Память и новые данные | Отзыв источников, каскад устаревания выводов, журнал пересмотра |
| Skills, роли, хуки | Файлы навыков; отдельные модельные вызовы; события до/после инструментов |
| Маршрутизация и экономичность | Базовая/проверяющая модели, резерв бюджета, учёт токенов и ошибок |
| MCP/CLI и переносимость | Один Toolbox для обеих интеграций, локальный проект без обязательной БД |

Число ролей и инструментов само по себе не является показателем качества. Нативное
распознавание изображений, аудио и видео, векторный поиск и измеренное превосходство над
аналитиком не заявлены. Границы и метод сравнения описаны в [оценке](docs/EVALUATION.md).

## Структура и проверка

```text
AGENTS.md / prompts/ / .agents/skills/   постоянные инструкции и процедуры
knowledge/                              методика
strategy_agent/                         CLI, OpenRouter, Toolbox, MCP, состояние
examples/                               брифы, открытые источники, учебные материалы
workspace/                              пользовательские проекты; исключены из Git
tests/                                  поведенческие проверки
docs/ / submission/                     архитектура и пакет для жюри
```

Подробнее: [архитектура](docs/ARCHITECTURE.md), [безопасность](docs/SECURITY.md),
[критерии и измерения](docs/EVALUATION.md). Код распространяется по MIT; ссылки и краткие
авторские пересказы публичных источников сохраняют атрибуцию первоисточников.

Видеоролик по текущему объёму работы отложен. Для окончательной конкурсной подачи
он обязателен; официальный бриф также нужно проверить после публикации.
