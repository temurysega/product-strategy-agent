# R06 — паспорт искусственных данных

Происхождение: synthetic. Автор: команда примера. Создано: 2026-11-08.
Ни одно число ниже не является внутренней метрикой МегаФона, результатом опроса
или реально проведённого эксперимента.

`funnel.csv`: шесть строк, два сценария и три последовательных этапа за один условный
28-дневный период. Единица — уникальная взрослая семейная пара; «invited» — знаменатель
для активации. Период `2026-10` — обозначение фикстуры, не дата проведения исследования.

`activation.csv`: две строки для независимого сравнения активации, 200 из 1000 и 260 из 1000.
Формула активации: обе стороны согласились и завершили пробную проверку / все приглашённые пары.
`economics.csv`: сценарные месячные величины, создаваемые автором; единица — рубль на платящую семью.

Синтетические данные нужны для демонстрации расчёта, проверки пропусков и пересмотра.
Они не обосновывают выбор сегмента, обещание роста, платёжеспособность или размер рынка.
