# Демонстрация «Круг доверия»

Авторский пример для проверки инструментария и качества ответа. Это не официальный бриф
МегаФона, не результаты проведённого пилота и не запись автономного LLM-прогона.
После публикации конкурсного брифа заменяются запрос и материалы; движок остаётся тем же.

- [Запрос и ограничения](brief.md).
- [Исследование и пробелы](outputs/research.md).
- [Четыре альтернативы и сильные возражения](outputs/options.md).
- [Продуктовая стратегия](outputs/product-strategy.md).
- [Коммуникационная стратегия](outputs/communication-strategy.md).
- [Эксперимент](outputs/experiments.md).
- [Решения и обязательства](outputs/decision-register.json).
- [Новые данные и пересмотр](outputs/changes.md).

В `manifest.json` описаны разрешённые материалы, в `sources.json` — URL и периоды.
`outputs/` — эталонный авторский разбор. Реальный ответ модели появляется в отдельной рабочей
папке; его нужно проверить, а не автоматически подменять эталоном.

Проверить арифметику из корня репозитория:

```bash
python examples/family-safety/reproduce.py
```

Сверка: `outputs/expected-analysis.json`. Скрипт использует только местные CSV, не требует
ключа и не отправляет данные. Результат имеет `provenance: synthetic` и `model_calls: 0`.
R08 подключается как новое условие отдельно, чтобы исходное исследование не смешивалось с ревизией.
