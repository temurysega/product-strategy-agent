# Продолжение и пересмотр

В новом сеансе: прочитай статус, последнее завершённое действие, открытые вопросы,
расходы, ожидаемое решение человека и список изменённых/отозванных оснований.
Не запускай всё исследование заново и не повторяй действие с тем же ID без проверки журнала.

Память хранит факт источника отдельно от авторского вывода, принятого решения и допущения.
У записи есть версия, дата, происхождение, локатор, статус и зависимости. Повторение старого
вывода не создаёт новый независимый источник. Автоматическое резюме не меняет тип утверждения.

Новое свидетельство сопоставь с существующим: добавляет, уточняет, противоречит, отзывает
или не относится. Отметь affected по графу зависимостей. Пересчитывай затронутое; не переписывай
независимые факты. Старые версии сохраняются и исключаются из актуального обоснования.

Решение связывается с человеком/ролью, обязательствами, сроком, метрикой и условиями пересмотра.
Роль без назначенного исполнителя — `unassigned`, не выполненное поручение.
Обновление стратегии становится `needs_review`, если меняет значимый выбор; агент не подделывает
утверждение человеком. Неизвестный исход сетевого запроса требует сверки до повтора расходов.
