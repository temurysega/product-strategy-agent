# Методическая база

Это методы, а не факты о проекте. Источники находятся в `materials/`, выводы — в `artifacts/`,
ход работы — в `state/`. Читать только метод, нужный следующему решению.

| Задача | Файл | Что меняет в работе |
|---|---|---|
| Неясный запрос и противоречивые основания | [research.md](research.md) | Сначала вопрос, способный изменить выбор, затем источник |
| Качественная проверка | [interviews.md](interviews.md) | Последний реальный опыт и опровержения вместо одобрения идеи |
| Проверка эффекта | [experiments.md](experiments.md) | Знаменатель, единица рандомизации, окно и правило остановки |
| Сравнение вариантов | [economics.md](economics.md) | Дополнительный вклад, чувствительность и цена упущенной альтернативы |
| Экран, текст, видео задачи | [ux.md](ux.md) | Наблюдение с локатором отдельно от интерпретации |
| Возвращение после перерыва | [memory.md](memory.md) | Версии, зависимости и отзыв основания |

Поиск использует формулировки и словарь понятий; он не доказывает семантическую эквивалентность.
Пример: «отток» → удержание, churn, cohort; «подключение» → активация, воронка, согласие;
«окупаемость» → contribution, CAC, payback. Совпадение — повод прочитать материал.
